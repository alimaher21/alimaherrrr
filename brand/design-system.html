The logo is a JPEG. That means no transparent background, visible compression fringing around the letterforms, and a hard ceiling on size — it cannot be printed on a banner or shown on a retina screen without blurring. Ask the client for the original vector file. If it no longer exists, redrawing it as SVG is a half-day of work and should be part of the rebuild quote.

Rules once a proper file exists

  • Clear space: keep the height of the "P" free on every side.
  • Minimum width: 120 px on screen, 25 mm in print.
  • On dark grounds: a white-and-orange version. Never the indigo logo on navy.
  • Never stretch, recolour, add effects, or place it on a busy photograph without a solid plate behind it.

The site's orange buttons use white text. That scores 2.8:1 and fails accessibility at every size — the floor for large text is 3:1 and for body text 4.5:1.

The fix keeps the logo orange exactly: put ink on it instead of white. Same colour, 6.5:1, passes comfortably. Do not darken the orange — that would stop being the brand.

Rules

  • If it is orange, it is clickable. Nothing decorative in orange, or the buttons stop reading as buttons.
  • Orange is a fill, never text. Orange type on a light ground fails contrast at any size. An orange link has to be a button.
  • Text on orange is ink, not white.
  • Every neutral is indigo. If a grey is needed, take it from the ramp above — never a generic grey, never a new hue.
  • One orange element per screen region. Indigo carries structure; orange carries the single thing you want pressed.

Body text is currently 13.3px. That is below the readable minimum on a phone and a large part of why the site feels cramped. Set the base to 16px.

And the site loads seven weights of Raleway that it never uses. The stylesheet requests Oswald:400,700 | Raleway:300,400,400i,500,600,700,900 while the CSS actually asks for Poppins. Every visitor downloads Raleway for nothing. Load Oswald 400/700 and Poppins 400/500/600, and nothing else.

Currently yellow, orange, blue and purple — four unrelated colours in one component. Replace with the indigo ramp, with the final cell in orange so the eye lands on the urgent end. Oswald 700 for digits, tabular figures so they stop jumping.

Arabic and right-to-left

The site already ships bootstrap-rtl.min.css and rtl.css, so the foundation exists. The rebuild must keep it.

  • Oswald has no Arabic. Pair it with a display Arabic face — Cairo or Tajawal — at the same optical weight. Never let Arabic fall back to a system font beside a styled Latin heading.
  • Arabic runs taller. Add roughly 15% line-height in RTL and do not set Arabic in all-caps or with letter-spacing — neither exists in Arabic typography.
  • Mirror the layout, not the logo. Navigation, arrows and progress flip; the logo and photographs do not.
  • Numbers and dates stay Western-Arabic (16–18) for an international trade audience, unless the client asks otherwise.
